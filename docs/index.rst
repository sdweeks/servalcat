Servalcat - X-ray crystallographic refinement
=============================================

Servalcat (for **S**\ tructur\ **e** **r**\ efinement and **val**\ idation for **c**\ rystallography and single p\ **a**\ r\ **t**\ icle analysis) is a software package for atomic model refinement and map calculation. This version is reduced to X-ray crystallography: refinement does not need REFMAC5.

Source code repository: https://github.com/keitaroyam/servalcat

Installation
------------
Please see https://github.com/keitaroyam/servalcat/blob/main/README.md#installation
